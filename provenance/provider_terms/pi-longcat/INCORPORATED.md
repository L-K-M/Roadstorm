The general Terms of Use §I.2 and §I.4 incorporate the API platform terms
and say both govern API use. The API platform terms state that they prevail
where agreements conflict. The general agreement §II.4 says that using the
service or its outputs for commercial purposes requires Meituan's permission;
§VI.2 describes the service-use right as non-commercial. The API platform terms
address developer applications, enterprise accounts and paid API service, but
their output-rights clause does not expressly state whether it overrides the
general commercial-output restriction. The user retains output rights under
both documents subject to agreement compliance, and the API terms require AI
content labeling when distributing output.

**Disposition: unresolved rights gate.** A standard public account, without
identified commercial-use permission, is insufficient evidence that LongCat
output may be shipped as unrestricted Unlicense/CC0 project material. Resolve
the interaction between the two agreements and the labeling duty before
release; do not infer permission merely from an available paid API endpoint.
The privacy policy was captured because the API terms incorporate it; this
review found no clause in that policy granting broader output-use rights.
