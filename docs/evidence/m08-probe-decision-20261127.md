Current captures show the exact earlier-observer failure, intact PASS controls and 137/1 summary; both reviewers audited them. Before changing labels or reusing this harness as a new gate, require explicit positive-control PASS labels and exact failure reconciliation.
- The frame-alignment evidence README incorrectly says both prior `b5c4f99` reviewers passed. The actual prior verdicts were **Opus pass** with R1 follow-up and **Sol changes required**; those reports, this correction and this decision supersede the introductory wording. The same README's “throughput (4) + trace (2) | 12 PASS” line mixes enforced check counts with printed PASS lines: the comparison has ten throughput/fidelity PASS lines and two trace PASS lines. The source hashes and captured measurements remain valid; correct the wording on the next evidence-document update without rewriting raw outputs.
- The coordinator runs at scene-local physics priority -1000. A node with still-earlier priority can observe the publication iteration, and pausable idle `_process` work can run after the final server step but before the next coordinator callback. M1 integration must explicitly gate such work; no blanket pause guarantee is accepted.
- Contact manifold and `Area3D` freshness, the final motor/world collision interface, full multi-car reset, actual controller/input latency and target-platform behavior remain M1/M3/M4B work. This decision does not satisfy those gates.
