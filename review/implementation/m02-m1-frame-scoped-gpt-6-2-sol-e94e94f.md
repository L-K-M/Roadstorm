Evidence in `logs/starter-assertions.log` and `logs/comet/bake_manifest.json`.
2. **High · C · Finite input can bypass the heading tolerance and emit an invalid success record.** `tools/frame_trace_lab/compare_frame_traces.py:427` subtracts heading values before modular reduction. The finite check at lines 347–349 admits both `1.7e308` and `-1.7e308`. On the frozen 30/60/120 cohort, set only `endpoint.heading_deg` to `1.7e308`, `-1.7e308`, and `1.7e308` respectively. The mixed-sign differences overflow before the modulo operation. The two pair metrics become `NaN`, the tolerance comparison at line 474 accepts them, and the maximum stays zero. Exit 0 with `"pass":true` and literal `NaN` in the marker. A related coordinate test sets only the 60 FPS endpoint position to `[1.7e308, 1.7e308]` and exits 1 with literal `Infinity` in the marker. Require finite derived metrics before comparison and serialization, and either check the producer's heading domain or normalize finite operands before subtraction. Both examples use valid JSON inputs. The arithmetic predates this patch, but the outcomes contradict the repaired comparator's structured refusal and tolerance contract. Reproductions and command in `logs/check-frame.py`, `logs/heading-overflow*.json`, `logs/heading-overflow.log`, and `logs/finite-coordinate-overflow.*`.
3. **Medium · C · Plausible totals can contradict the recorded callback indices.** `tools/frame_trace_lab/compare_frame_traces.py:234` checks the engine counters independently of the row callback indices. Line 386 requires the indices to increase. In the frozen 60 FPS trace, set every callback index to `10000 + 2 * zero_based_row`, leaving the 1,204 measured physics frames and timing callbacks intact.
