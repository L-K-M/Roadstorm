## Component boundaries and controls

`propose()` advances the gearbox immediately and returns a detached result. `restore_state()` validates and copies the gear, cooldown and RPM against the destination’s configuration bounds. `mirror_gear()` reads only the receiving gearbox’s canonical state, so mutating or retaining a stale or foreign proposal cannot change the mirror. The same-valued-then-diverged test checks instance isolation. The API accepts a finite car record without checking its owner or tick, and a numerically compatible state from another configuration can restore by design. Integration must pair the correct car, configuration, tick and state, schedule one gearbox advance per accepted tick, and emit only that tick’s shift event.
