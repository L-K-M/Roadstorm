## Ranked implementation findings

### 1. High — the float32 length bracket can accept an error above 1 mm

The chord/control-polygon theorem applies in exact arithmetic. Here, the bracket uses rounded `Vector3.length()` values for both bounds, and the Simpson speed evaluation uses the same float32 norm operation. Agreement between the two can therefore hide a common error. The `1e-12` relative allowance is used for comparisons and is excluded from the reported error. It does not enclose float32 norm or control-point evaluation error. [Leaf acceptance](src/course/road_arc_sampler.gd#L840), [geometric bounds](src/course/road_arc_sampler.gd#L996), [derivative and speed](src/course/road_arc_sampler.gd#L1606)

A source-derived counterexample is a straight OPEN span with controls `Pᵢ = (8192i, 0, 8192i)` for `i = 0, 1, 2, 3` and sample spacing `65536 m`. On the default float32 vector path, the dyadic evaluations used by the initial leaf have exactly representable components. The error comes from the norm rounding:

- The exact length is `24576√2 ≈ 34755.712509 m`.
- Simpson integrates a constant rounded speed of `34755.7109375 m`. The eight rounded chords sum to the same value.
- The 24 rounded control-polygon edges sum to `34755.7119140625 m`. This computed upper bound falls below the exact length.
- The accepted leaf reports `0.0009765625 m`, within the `0.001 m` default. Its actual error is approximately `0.001571 m`. With the stated spacing the table needs only its two endpoint samples, so fixed-panel inversion plays no part in this example.

This is an arithmetic derivation from the reviewed source. The pinned engine did not execute this case in this review. Compute the bracket in local coordinates with sufficient precision and outward error allowances, including accumulation, or return a structured precision refusal when the tolerance cannot be supported. Add the diagonal case and a translated tight-spacing case to the existing lab. Check that an accepted result satisfies both the requested tolerance and its own reported bound against an independent reference.

### 2. Low — hairpin ownership prose promises a sharper boundary than the filter enforces

The previous interior tag corruption is addressed. The filter checks both section and surface against recorded station intervals and separately checks duplicated joins for order, equality of position, and adjacent section IDs. The ownership helper expands both ends of each interval by `1e-4 m`, so a raw sample just to one side of a join can claim either adjacent section. The duplicate join check also uses a station tolerance. The current fixed fixture’s ordinary interior samples are far from that band. Document the tolerance or reserve dual ownership for the recognized duplicate pair if exact boundary ownership is required. [Filter and duplicate checks](tools/calibration_hairpin_path_lab/calibration_hairpin_path_source.gd#L547), [ownership intervals](tools/calibration_hairpin_path_lab/calibration_hairpin_path_source.gd#L1015)

## Prior findings and scoped inspection

**Arc.** The new integration path combines adaptive Simpson with an eight-piece geometric bracket and subdivides or refuses when acceptance fails. The global station check now explicitly refuses `total_length <= span_start` after a positive local span. The regression supplies the `2^53 m` prefix followed by a `0.25 m` span and requires the specific station-advance refusal. The quadratic regression targets `B(t) = (t, 5t² − 3.17t, 0)`, exact total `3.1086978942948535 m`, and checks positions, tangents and interior station correspondence. The two historical Opus controls use a separate fine midpoint reference against the parsed control points. The packet’s approximately `0.00008681 m`, `0.00000151 m`, and `0.00000080 m` discrepancies for quadratic, road1 and hook respectively remain coordinator measurements. The regressions compare reference agreement and estimate limits separately. They should also assert that the reported bound encloses the reference discrepancy, with an allowance for reference error. [Global station guard](src/course/road_arc_sampler.gd#L424), [quadratic and historical controls](tools/road_sampling_lab/road_sampling_checks.gd#L776), [collapse regression](tools/road_sampling_lab/road_sampling_checks.gd#L940)

**Inversion and station geometry.** Inversion uses a bounded Newton/bisection search against fixed 8/16-panel Richardson estimates. Its final residual is measured against that partial integral and the accumulated nominal node prefix. Exact nominal node hits return zero inversion residual and estimate even when the prefix length differs from the true length. The README already distinguishes this metric from a physical station-error bound. I established no separate fixed-panel defect from the available evidence. Float32 output position is an additional limit: at large coordinate offsets, a strictly increasing station grid can request increments smaller than a `Vector3` coordinate step, allowing coincident or poorly spaced output positions. The current output checks cover finiteness and station order. Before mesh consumers rely on spatial spacing, define the supported coordinate/spacing envelope and verify it with independent position and station references. [Inversion](src/course/road_arc_sampler.gd#L1056), [fixed-panel quadrature](src/course/road_arc_sampler.gd#L1195), [sample validation](src/course/road_arc_sampler.gd#L1537), [documented inversion limits](tools/road_sampling_lab/README.md#L128)

**Hairpin.** `_required_scalar` checks presence, numeric type and finiteness before expected-value comparisons. The guards cover bay width, section start/end/length fields, raw stations and the fixture fields at issue in the prior decision. `grip_entry` is required and checks its own initial speed and heading. The lab includes missing/nonfinite scalar cases and wrong section/surface tags. The circle comment is corrected to describe the roughly 2.73 mm outward offset from midpoint stepping while retaining the existing 1 cm fixture tolerance. [Fixture authority and speeds](tools/calibration_hairpin_path_lab/calibration_hairpin_path_source.gd#L327), [scalar guard](tools/calibration_hairpin_path_lab/calibration_hairpin_path_source.gd#L896), [negative cases](tools/calibration_hairpin_path_lab/calibration_hairpin_path_checks.gd#L782), [circle comment](tools/calibration_hairpin_path_lab/calibration_hairpin_path_checks.gd#L18)

**OPEN frame.** The component rejects closed tables explicitly. It seeds from world up with a deterministic right-axis fallback near vertical, then uses the cross/dot shortest rotation between neighboring tangents. The near-antiparallel cutoff deliberately includes exact reversal. Re-orthonormalization checks finite unit axes, orthogonality and a determinant near `+1` for `Basis(right, up, -forward)`. Positive bank rotates canonical `+X` road-right down around canonical `-Z` forward. The next sample transports the unbanked basis, so bank does not accumulate. The result carries station, section, surface and other sample metadata, and copies the frame and summary containers on construction and access. The lab supplies straight, graded/banked, return-to-zero, near-vertical, copy-safety, reversal and closed cases. The near-vertical seed threshold can switch initial roll abruptly across two independently authored starts. That is a deterministic seed policy and does not reset transport at later samples. [Build and copied fields](src/course/road_transport_frame.gd#L288), [copy accessors](src/course/road_transport_frame.gd#L163), [seed, transport and bank](src/course/road_transport_frame.gd#L708), [basis validation](src/course/road_transport_frame.gd#L889), [supplied cases](tools/road_frame_lab/road_frame_checks.gd#L441)
