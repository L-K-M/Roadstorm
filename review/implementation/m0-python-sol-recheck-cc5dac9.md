## Ranked findings

1. **High · A recording destination can destroy checked inputs and still report success.** [The recording block](../../tools/python_pin/verify.sh#L339) opens the requested destination with truncating redirection after checks. In separate probes `--archive FILE --record FILE` returned 0 and replaced a digest-matching archive, and `--record PIN_FILE` returned 0 and replaced the pin metadata. Both probes used plain regular files with no links. Fail before opening a destination that aliases the archive, interpreter, or pin inputs. A fresh-file-only recording contract with exclusive creation is one way to prevent the observed data loss. Test the collision cases and confirm that checked inputs retain their bytes and that ordinary recording still works.
2. **Medium · Recording disregards `--no-interpreter`.** The main check honors the flag, but [the recording loop](../../tools/python_pin/verify.sh#L349) rediscovers interpreters and directly invokes the selected executable. I supplied a private shell stub with a marker side effect. The marker was created under `--no-interpreter --record`, even in a run with a digest-mismatching archive. Have recording reuse already observed data so explicitly skipped inputs stay skipped. Define whether failed checks may still write diagnostic observations and keep any such output clearly identified.
3. **Medium · An ordinary archive path containing spaces fails.** [Argument collection and iteration](../../tools/python_pin/verify.sh#L381) flatten archive paths into a space-separated string. I passed a correctly quoted absolute path for the same matching regular file in a directory named `space dir`. The verifier split the path and returned 1. Preserve individual path arguments in verification and recording, including paths containing glob characters. Interpreter candidate and recording loops also split paths through command substitution and should preserve argument boundaries.
4. **Low · One runtime summary overstates an installer digest match.** [The distinction banner](../../tools/python_pin/verify.sh#L317) says matching an installer authenticates its bytes. This run only compares a digest. Reserve authentication language for the separately recorded Sigstore result and state explicitly that a digest match establishes agreement with the pinned digest.
