## Findings

1. **High — Validate rejects its own tracked ignore file.** `tools/ci/ci.sh:924–932` counts every tracked path under the default output directory. The candidate tree contains precisely `tools/ci/out/.gitignore` in that directory. Hosted Validate failed with the one-file count. The archive tests skip this check because the snapshot has no Git index. Exempt the exact intentional sentinel or relocate it, and cover the indexed case.
2. **High — The hosted Ubuntu export selects Xcode signing.** `export_presets.cfg:99` sets `codesign/codesign=3`. Godot's pinned source fails preset validation with this value if neither `/usr/bin/codesign` nor `/bin/codesign` exists. The hosted job uses Ubuntu at `.github/workflows/ci.yml:229`, passes template preparation, then stops at the macOS preset with a configuration error. Use a signing mode supported by the export host. `tools/ci/ci.sh:1778–1782` prints only error-prefixed lines, which hides the specific multiline configuration diagnostic from the hosted log. Preserve the captured export log or print those details when this step fails. [Pinned Godot exporter](https://github.com/godotengine/godot/blob/ed1daf0bf/platform/macos/export/export_plugin.cpp#L2590-L2605)
3. **High — Relative workflow paths place outputs under the scratch project.** `.github/workflows/ci.yml:356–358` passes `build/<name>`, which `tools/ci/ci.sh:1773–1791` gives to Godot alongside the scratch project's `--path`. The wrapper then looks for the output in the checkout. I reproduced Godot exit 0 followed by CI exit 1 and “export produced no output” for all three presets, with the binary or ZIP and any sidecar present under `project-copy/build/`. All three absolute path controls returned 0. Resolve the output argument against the caller's directory before passing it to Godot. The existing engine-backed regression at `tools/ci/tests/run_tests.sh:1630–1631` supplies an absolute path.
4. **Medium — A nested project warning fails the Jolt physics gate.** `tools/ci/scripts/warning_watch.sh:117` and `tools/ci/lib/common.sh:256–258` match the substring `jolt` anywhere in an unexpected warning. Both can interpret a path mentioning Jolt as a backend diagnostic. The hosted warning watch failed on the benign import warning for `res://tools/jolt_inventory`. Passing that single line to the candidate warning watch reproduced exit 1. Match actual physics message shapes in shared code and exercise the nested project as a nonfatal control.
