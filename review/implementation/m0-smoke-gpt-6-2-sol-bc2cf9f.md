## Ranked findings

1. **High · New · Archive capture and validation can deadlock.** `tools/export_smoke/lib/common.sh:250–271` waits for stdout EOF before draining stderr. A child blocked on a full stderr pipe cannot close stdout. The same problem occurs with an empty error path. The private probe ran a child that writes one byte to stdout, then 1 MiB to stderr. The two-second watchdog killed the process group. Git and both tar listing calls use this helper outside the export timeout. Pass the already-open descriptors directly to the child, use a sink when stderr is omitted, and bound the invocation. Direct descriptor output also removes the pump's unchecked short `os.write` calls.

2. **Medium · New · A nonregular preset opened after the check can hang the snapshot.** `tools/export_smoke/lib/common.sh:299–310,384–399` checks `-f` separately from blocking `open(O_RDONLY)`, then reads until EOF without checking the opened type. The private call to `_es_copy_exclusive` with a FIFO and no writer timed out in two seconds, leaving the error file and never opening the destination. A stable FIFO at the entry point fails the earlier shell check. Replacing a regular source between check and open can still reach the blocking call, and the historical tests deliberately allow a symlink to a regular preset. Open nonblocking, require a regular descriptor via `fstat`, and handle short destination writes. This is a source-validation issue, independent of the destination's exclusive open.

3. **Medium · Inherited · A platform typo reports a successful export of zero packages.** `tools/export_smoke/run_export_smoke.sh:137,368–372,445–463` accepts any platform string and skips unknown tokens without setting failure. The exact runner with `--platform Linuz` and an engine stub that can only answer `--version` returned 0 with no export or inventory run. A mixed valid/invalid list also ignores part of an explicit request. Validate every platform before reservation. The report also prints affirmative packaging booleans on failed exports, including in the separate Linux stub race, irrespective of whether inventory ran.

4. **Medium · Inherited · The full macOS probe can pass without a working windowed launch.** `tools/export_smoke/launch_macos_app.sh:104–125,145–178` only changes the verdict on headless failure. A private executable printed the expected headless markers and exited 0, then exited 7 immediately in windowed mode. The launcher returned 0 and printed PASS with no screenshot. Screenshot failure is likewise ignored. The display-only `codesign` command's status is ignored and the runner unconditionally prints a signature and arm64 launch note after the attempt at `run_export_smoke.sh:435`. Tie windowed and signature claims to observed evidence. The accepted `--launch-timeout` option is unused at `run_export_smoke.sh:105,124–125,419–424`, and the launcher uses a hard-coded 120 seconds at line 109.

5. **Medium · Same-UID replacement boundary · The documented no-truncation guarantee is stronger than the implementation.** `tools/export_smoke/lib/common.sh:379,581–585` opens the archive's stderr file exclusively, then reopens that pathname with `2>` for extraction. In the private fixture, supplying a replacement symlink at that path truncated its sentinel target even though extraction itself stayed confined to the snapshot inode. It also discards successful archive warnings in an ordinary run. Separately, `launch_macos_app.sh:137–146` reopens the exclusively created windowed log with `>`, and inventory report and JSON paths are opened with `w` at `lib/pack_inventory.py:431–433,658–665`. Report, sums and other log appends can follow replacement names and modify foreign files. The README acknowledges pathname reopens at lines 188–196 but then denies follow and truncation. The deterministic sentinel probe requires an actor able to replace a private path. An ordinary concurrent invocation using the same explicit output cannot reach these reopens. Use descriptor-based writes or exclusive creation where feasible, keep distinct archive/extract diagnostics, and describe remaining pathname limits accurately. Archive validation, extraction and hashing also reopen the staged archive by pathname, so their binding assumes that private files remain stable. The destination identity is sampled after mkdir at lines 554–558, leaving an additional malicious replacement interval before an identity is recorded.

6. **Low · Inherited, unchanged inventory · Source comparison can accept a path outside the snapshot.** `tools/export_smoke/lib/pack_inventory.py:195–196,359–389` applies policy to raw pack path strings and uses `os.path.join(snapshot, path)` without checking containment or canonical form. A private synthetic entry named `../sentinel` matched a sibling file by MD-5 and produced no policy failure when the other required paths were present. This was a direct content-policy test, with the PCK parser and engine bypassed. It shows a validation gap for malformed packs. There is no evidence the pinned exporter generated such paths here. Validate normalized resource paths before policy or source lookups.
