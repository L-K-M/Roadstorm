## Ranked findings

1. **Medium — Audio can raise a script error on incompatible input instead of returning `false`.** `VehicleFeedbackPlayer.apply()` accepts untyped values. Once setup completes, `apply(17, valid_command)` reaches `17.has_method("is_finite")`. An object that passes the initial method check can also reach unchecked calls to `speed_m_s()` and `slip_deg()`. These calls bypass the documented refusal path and its error reason. The existing incompatible-input checks use plain `RefCounted` objects, which exercise the first method guard but miss both routes. Check for the actual `CarState` and `DriverCommand` types before member access, and extend the atomic-refusal test to cover a primitive and a partially compatible object. The ordinary DriveLab path supplies committed, typed records, so this finding concerns the new component API. [vehicle_feedback_player.gd:204](../../src/audio/vehicle_feedback_player.gd#L204) · [validate_audio_playback.gd:437](../../tools/audio_playback_lab/validate_audio_playback.gd#L437)

2. **Low — Gearbox invalid-state documentation and implementation disagree.** The class contract promises atomic refusal for a nonfinite car state. `propose()` checks velocity, heading, and projected speed, and its own method comment describes that narrower rule. A car with finite motion, `position_m.x = NAN`, and forward speed of 20 m/s passes those guards and advances a fresh default gearbox to third gear. The test covers nonfinite motion fields and invalid `dt`. Decide whether the input boundary requires a fully finite committed record or validates only the consumed motion fields, then align the class and lab contracts and pin the choice with a regression case. 3. **Low, latent — Rotated spawn heading is fixed, but the course limit still uses a world axis.** `get_road_station_m()` and `_course_limit_reached()` use the road-plane Y displacement regardless of authored straight yaw. At +30°, 500 m of authored forward travel reports 433.013 m. At +90°, it reports zero. The test overlays a rotated marker or manifest yaw after building the geometry and checks a short acceleration trace, which establishes the heading conversion. If rotated straights are used for full runs, project displacement onto the fixed authored straight axis and cover the end and reverse limits. This does not affect the current zero-yaw straight.
