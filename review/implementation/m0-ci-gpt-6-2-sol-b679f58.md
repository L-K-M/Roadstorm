## Descriptor and verdict handling

The parent opens fd 7 read-only on the private body before publication and leaves it open through the worker call. The worker derives identity from `fstat(7)`. The exported numeric identity has no authority, and fd number `7` in the environment alone is insufficient. The live descriptor prevents inode reuse after unlink. Build gates also require a matching regular pathname and attempt header. A caller who deliberately supplies both an open fd 7 and matching handoff inputs can impersonate a parent. This is an internal process handoff under the caller’s authority. [common.sh:1057](tools/ci/lib/common.sh#L1057), [common.sh:1125](tools/ci/lib/common.sh#L1125), [ci.sh:2156](tools/ci/ci.sh#L2156)

I traced the build verdict calls through the early guard, report publication, lock and preflight refusals, writer and inventory failures, and final success. Build calls share `ci_report`. The bound helper opens with `O_APPEND`, `O_NONBLOCK`, and `O_NOFOLLOW` on macOS and Linux, omits `O_CREAT`, and checks the opened object’s type and identity before writing. A failed FAIL append leaves the command in failure with its diagnostic. A failed PASS append returns failure, and a successful append still requires the final pathname recheck before success prints. Python-less Linux can reserve a report for `pin` through GNU `ln -T`, while a build without descriptor identity refuses before the writer. Shells that close fd 7 at exec also fail closed at worker entry. [common.sh:1176](tools/ci/lib/common.sh#L1176), [common.sh:1255](tools/ci/lib/common.sh#L1255), [ci.sh:2567](tools/ci/ci.sh#L2567), [README.md:122](tools/ci/README.md#L122)

## Ranked residual findings

1. **Low — The descriptor header comparison can accept malformed bytes.** Python emits the first line to shell command substitution, which discarded NULs in both shells I probed. A line containing an extra NUL can therefore compare equal. The helper also accepts a matching unterminated prefix if it fills the entire 4,096-byte window. Normal reservation writes a short ASCII token and newline, so these cases require malformed inherited data or an in-place edit of the genuine inode. Comparing bytes and requiring a newline within the read window would enforce the documented exact-first-line rule. [common.sh:1299](tools/ci/lib/common.sh#L1299), [README.md:122](tools/ci/README.md#L122)
2. **Low — The new tests cover the repaired mechanisms with two integration gaps.** The namespace test reaches the early guard and checks that it preserves existing bytes before any Godot invocation. Its missing-path companion tests a path already missing at entry, so it does not distinguish the old shell guard from the new no-create guarantee. The symlink unit test distinguishes `lstat` from the old `stat`, but does not inject a symlink at the final post-append seam. The bounded FIFO test arms the old `awk` open seam and checks that it never fires. It catches reintroduction of that open when the seam is reached, but its nonzero-exit assertions also allow an unrelated earlier failure. The positive descriptor-header case and successful export cases provide complementary coverage. Hosted CI requires the new success markers and the native `ln -T` marker. [run_tests.sh:466](tools/ci/tests/run_tests.sh#L466), [run_tests.sh:3511](tools/ci/tests/run_tests.sh#L3511), [run_tests.sh:3702](tools/ci/tests/run_tests.sh#L3702), [run_tests.sh:4028](tools/ci/tests/run_tests.sh#L4028), [ci.yml:402](.github/workflows/ci.yml#L402)
3. **Low, pre-existing — The separate package-inventory report still has a pathname-read race.** A local actor able to replace that report between its shell type checks and any of the three `grep` opens can substitute a FIFO and stall verification. The repaired descriptor protects the attempt report only. The attempt report itself remains mutable in place by a writer with access, and its advertised name can change after the final recheck. These limits require local interference and do not affect normal invocation. [ci.sh:2514](tools/ci/ci.sh#L2514), [ci.sh:2574](tools/ci/ci.sh#L2574)
