### Added

- Complete multi-milestone plan for an original four-player split-screen
  arcade racer, including game design, technical design, opponent AI, asset
  production, benchmarks, verification and release gates.
- Godot 4.7.2 placeholder shell with pinned Jolt physics, fixed-tick settings,
  GL Compatibility rendering, export presets, and original project structure.
- Digest-verified engine/tooling chain, isolated CI driver, headless import
  and validation, runtime-error gates, warning watch, deterministic capture
  preparation, and frozen-source native export smoke packaging.
- Schema and fixture contract suites for handling, observation, intent,
  scenario and Python-toolchain behavior, plus detailed provenance and license
  inventory foundations.
- Project tooling baseline: agent instructions, build and release entry
  points, CI hardening, Dependabot, and the GLM/StepFun review workflow.
